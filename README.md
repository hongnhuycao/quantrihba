# HBA Quản trị

Trang quản trị HBA trên GitHub Pages: https://hongnhuycao.github.io/quantrihba/

| File | Dùng cho | Số liệu |
|---|---|---|
| `index.html` | Link gốc, toàn bộ app HBA QUẢN TRỊ (chỉ xem) | Đọc trực tiếp Google Sheet qua Apps Script, mỗi lần mở là số mới |
| `tgd.html` | Link TGĐ: Dự án & Nhân sự | Như trên, chỉ các bảng dự án và nhân sự (không có giá trị hợp đồng, thu chi, dòng tiền) |

- Mở link sẽ thấy ô nhập mật khẩu. Nhập đúng thì trang hiện số liệu (mã được Apps Script kiểm tra, mật khẩu không nằm trong code).
- Có thể mở thẳng bằng `?k=…` ở cuối link để bỏ qua bước nhập.
- Trang trên GitHub chỉ để xem. Sửa, ghi sổ hay cấp số vẫn làm trên app claude.ai.
- Số liệu lấy qua Google Apps Script "HBA TGD" (Ứng dụng web), chạy bằng tài khoản chủ app, chỉ đọc.
